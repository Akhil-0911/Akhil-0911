# Setup (5 minutes)

1. Upload every file in this zip straight into the root of the repo `Akhil-0911/Akhil-0911`. No folders.
   Delete the old `assets/` folder first.
   (Optional) `snake.yml` must live at `.github/workflows/snake.yml`, because GitHub only runs workflows from there. Skip it if you do not want the snake; delete the snake block at the bottom of the README too.
2. Repo Settings > Actions > General > Workflow permissions: **Read and write**.
3. Actions tab > "Generate contribution snake" > Run workflow (once).
4. To edit text or colours in any graphic: change `gen2.py`, run `python3 gen2.py`.
